# Übung 5 — Skills und Werkzeuge für Agenten

In dieser Übung schreiben Sie einen Skill für das Corporate Design der THM,
bauen mit ihm das Steckbrief-Verzeichnis aus der Vorlesung nach und
schreiben in opencode einen eigenen Agenten. Die Aufgaben stehen im
[Übungsblatt](https://carstenlucke.github.io/thm_wk-1208_softwaretechnik/ue05-skills-werkzeuge/).

## Was Sie einreichen

Nichts. Zu dieser Übung gibt es keinen Pull Request und keinen Bonuspunkt
für das Blatt; die Fragen zum Übungsblatt folgen in der Vorlesung und
können alle Aufgaben betreffen.

Sie arbeiten trotzdem in Ihrem Klon dieses Repositorys, und zwar auf dem
Branch `ue05-<benutzername>` im Verzeichnis `ue05/<benutzername>/`. Gemeint
ist Ihr GitHub-Benutzername in Kleinbuchstaben. Dort entstehen:

| Datei | Aufgabe |
|---|---|
| `thm-cd/SKILL.md` | 1 — Ihr Skill für das Corporate Design der THM |
| `farbprobe.html` | 1 — die Seite, an der Sie den Skill erproben |
| `steckbriefe.html` | 2 — das Steckbrief-Verzeichnis im Corporate Design |
| `.opencode/agents/primzahl.md` | 3 — Ihr eigener Agent für opencode |

Ihre Commits bleiben lokal. Den Branch übertragen Sie nicht, und einen Pull
Request stellen Sie nicht.
