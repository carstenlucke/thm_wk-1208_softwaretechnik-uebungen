# Anforderungen — Terminplaner für die THM

- **A01** (FA, Lehrende): Lehrende können Zeitfenster für ihre Sprechstunde anlegen, ändern und löschen.
- **A02** (FA, Studierende): Studierende sehen alle freien Termine einer Lehrperson in einer Liste.
- **A03** (FA, Studierende): Studierende können einen gebuchten Termin selbst wieder absagen.
- **A04** (FA, Lehrende): Lehrende können für eine Prüfung mehrere Zeitfenster auf einmal anlegen.
- **A05** (QA, Lehrende und THM): Eine Lehrperson schafft es ohne Anleitung, in unter fünf Minuten ihre erste Sprechstunde anzulegen.
- **A06** (QA, Studierende): Alle Seiten lassen sich auf dem Smartphone ohne seitliches Scrollen bedienen.
- **A07** (QA, THM): Das System ist während des Semesters zu mindestens 99 % der Zeit erreichbar.
- **A08** (RB, Datenschutzbeauftragte): Es werden nur die Daten gespeichert, die für die Terminvergabe wirklich nötig sind.
- **A09** (RB, THM): Umgesetzt wird das System von einem Entwicklungsteam der Hochschule, nicht von uns.
- **A10** (QA, Studierende und Datenschutzbeauftragte): Studierende sehen bei fremden Terminen nur „belegt“, aber nicht, wer gebucht hat.

## Eine Anforderung, die niemand ausgesprochen hat

A10: Im Gespräch hat das niemand gesagt, weil es selbstverständlich wirkt. Bei den Listen an der Bürotür standen die Namen sogar offen da, deshalb ist keinem aufgefallen, dass das im neuen System nicht mehr so sein darf.
